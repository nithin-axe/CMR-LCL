# Norway Automation Hub (India Filling)

This project contains the backend core, UI templates, prompts, and Playwright automation scripts to automate tracking cargo, checking emails, reading/writing spreadsheets, and parsing invoices.

## Quick Start

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Configure `.env` with actual keys.
3. Start the application:
   ```bash
   python run.py
   ```
4. Access the dashboard via browser: `http://localhost:5000`
